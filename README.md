This guided exercise requires that students have determined data suitable for Michaelis-Menten kinetic plots in units of deltaAU/min and know how much enzyme (in mg) was added to each reaction. This notebook helps them calculate activity and plot MM, LB and EH plots. It uses nonlinear regression to determine Vmax and Km from the MM plot after initial estimation. The notebook helps students plot linearized date in LB and EH formats and returns a best fit line, but stops short of determining Vmax and Km from these plots and encourages students to develop code to calculate kinetic parameters from the best fit line.
